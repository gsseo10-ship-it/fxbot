# AutoProfit Bridge

This project implements an automated trading bot designed to profit from the Forex market using various strategies. The base structure will include scripts for trading, data handling, and configuration management.

## Directory Structure
- `autobot/`
  - `__init__.py`
  - `trader.py`
  - `data_handler.py`
  - `strategies.py`
- `config/`
  - `config.yaml`
- `setup.py`

## Installation
To install the project dependencies, run:
```bash
pip install -r requirements.txt
```

## Usage
To start the bot, run:
```bash
python autobot/trader.py
```
